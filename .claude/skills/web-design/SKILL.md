# web-design

> Adaptación de https://github.com/KAOPU-XiaoPu/web-design (MIT)

## Proceso: especifica primero, código después
1. Define el contenido real del currículum (nombre, experiencia, educación, habilidades, contacto).
2. Diseña la estructura visual en mente o en boceto: hero, resumen, experiencia, educación, habilidades, contacto.
3. Escribe el HTML semántico (`header`, `main`, `section`, `footer`).
4. Aplica CSS con variables, grid/flexbox y tipografía responsiva.
5. Autoaduítate contra el checklist de calidad.

## Checklist de calidad (100 puntos simplificado)
- [ ] HTML semántico y válido.
- [ ] CSS sin `!important` abusivo.
- [ ] Diseño responsivo en móvil y escritorio.
- [ ] Colores con suficiente contraste.
- [ ] Imágenes (si las hay) con `alt`.
- [ ] Página abre directamente en el navegador sin pasos de build.

## Nota
Este sitio es estático: no hay framework, bundler ni paso de compilación. Abre `index.html` directamente.
