# certificados/

Aqui van los PDF de las certificaciones, para que el sitio pueda enlazarlos.

## Aviso

**Todo lo que se ponga en esta carpeta se publica.** El repositorio es publico y
GitHub Pages sirve todos los archivos de la rama `main`, este enlazado o no.
Un PDF aqui es descargable por cualquiera que conozca o adivine la URL.

No subir aqui: documentos de identidad, certificados medicos, diplomas con datos
personales sensibles ni nada que no querrias ver indexado.

## Nombres de archivo

Minusculas, sin tildes, sin espacios, guiones en lugar de espacios.

| Certificacion | Archivo esperado |
|---|---|
| MongoDB Overview: Core Concepts and Architecture | `mongodb-core-concepts.pdf` |
| Curso de Supabase. Backend as a Service (BaaS) | `supabase-baas.pdf` |
| GCI World April 2026 | `gci-world-2026.pdf` |
| AI Literacy (IBM SkillsBuild) | `ibm-ai-literacy.pdf` |
| On-Chain Analysis for Beginners (Binance Academy) | `binance-on-chain.pdf` |
| Talento Tech - Curso Analista de datos Intermedio | `talento-tech-analisis-datos.pdf` |
| Talento Tech - Curso Programacion Intermedia | `talento-tech-programacion.pdf` |

## Peso

Un PDF de credencial no deberia pasar de 1 MB. Si viene mas grande, se comprime
antes de subirlo. No hace falta que sea el original de alta resolucion: es una
credencial de consulta.

## Despues de subirlos

Los enlaces no se agregan solos. Al terminar, avisar para conectar cada
`<li>` de la seccion de certificaciones en `index.html` con su PDF.
