# Referencias visuales

Imágenes entregadas por el dueño del proyecto el 2026-11-10 como producto final
del rediseño "Portfolio nocturno con ondas de luz". Son material de referencia
local: no se versionan, no se publican y no forman parte del sitio. Las cinco
imágenes mandan sobre `docs/diseno.md` en lo visual y estructural; `content.md`
manda en los datos reales, enlaces y privacidad.

> Estos PNG están excluidos por `.gitignore`. GitHub Pages publica la raíz del
> repositorio, así que no deben agregarse al historial ni enlazarse desde el
> sitio.

| Archivo | Sección de referencia |
|---|---|
| `01-hero-ondas.png` | Hero con ondas de luz y tarjeta de perfil |
| `02-proyectos.png` | 01 / Proyectos |
| `03-sobre-mi.png` | 02 / Sobre mí y "Mi camino" |
| `04-certificaciones-contacto.png` | 03 / Certificaciones, 04 / Contacto y pie |
| `05-ultimapagina.png` | 04 / Contacto en dos columnas y pie |

Los nombres originales tenían espacios y tildes; se renombraron con nombres ASCII
para que funcionen igual en Windows y Linux, aunque solo existan en local.

La extracción de textos y la dirección de arte están en `docs/diseno.md`.
